# RadioDept

## Local development

```sh
npm ci
npm run dev
```

To preview the production build locally, run `npm run build` and then `npm run preview`.

## GitHub Pages

In the repository’s **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**. Pushes to `main` build and publish the `dist` directory. You can also run **Deploy RadioDept** from the Actions tab.

The published site is [RadioDept](https://bongdraper.github.io/RadioDept/).
